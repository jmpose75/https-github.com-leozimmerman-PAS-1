# Requisitos para el módulo 2

Antes de empezar el módulo 2 tenés que tener instalado y funcionando:

- **JUCE 9.0.5**, con Projucer y la *Global Paths* apuntando a la carpeta de JUCE. [Descarga](https://github.com/juce-framework/JUCE/releases)
- **IDE y compilador de C++**:
  - macOS: [Xcode](https://developer.apple.com/xcode/)
  - Windows: [Visual Studio Community](https://visualstudio.microsoft.com/es/vs/community/) 2022 o 2026, con *Desarrollo para el escritorio con C++*
  - Linux: las [dependencias de JUCE](https://github.com/juce-framework/JUCE/blob/master/docs/Linux%20Dependencies.md)
- **[CMake](https://cmake.org/download/)**
- **[Git](https://git-scm.com/downloads)** y una interfaz gráfica ([SourceTree](https://www.sourcetreeapp.com/) o [GitHub Desktop](https://desktop.github.com/))
- **Cuenta de [GitHub](https://github.com/)**: logueada en las herramientas Git de tu computadora. 
- **Este repositorio ([PAS-1](https://github.com/leozimmerman/PAS-1)) clonado con Git** (no descargado como ZIP) y abierto en tu interfaz gráfica de Git
- *Opcional:* una herramienta de IA que funcione desde la terminal
