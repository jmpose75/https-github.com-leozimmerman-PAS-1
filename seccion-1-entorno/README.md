y vas a saber modificarlo con ayuda de una herramienta de IA desde la terminal.

| Bloque | Tema |

| 1.1 | **JUCE:** qué es, Projucer y CMake, anatomía de una Audio App |
| 1.2 | **Git:** repositorio, commits, diff, volver atrás, GitHub |
| 1.3 | **Terminal + IA:** comandos básicos, herramientas de IA y flujo de trabajo |

Usamos **JUCE 9.0.5**: <https://github.com/juce-framework/JUCE/releases>.
